# Listings

Listing match, watchlist refresh, and pair maps stay in Rocket. Swaps do not.

A hit becomes a dry-run `swap` command for [Whale](https://github.com/jhonnyisaacc/whale). `handToWhale` refuses `WHALE_LIVE=true` even when `WHALE_URL` is set. The checked-in client never posts.

`WHALE_URL` is the later HTTP address of the Whale executor. This package does not call it.
