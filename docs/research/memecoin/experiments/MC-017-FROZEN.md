# MC-017 frozen design — canonical PumpSwap route at the exit clock

Parent MC-012/MC-013/MC-015. The costed early-entry ranks failed, and a depleted/completed Pump bonding curve has been valued at zero only in a named stress scenario. This new, untouched ten-minute cohort asks whether a **canonical PumpSwap pool** is already present at a bounded read near creation receipt +67 seconds, especially for names whose Pump curve sell is unavailable. It does not test another entry score or claim an achieved fill.

## Protocol and acquisition

Pin the official Pump and PumpSwap IDLs to `pump-fun/pump-public-docs` revision `81091419e4457566469d4e2a27f64ed84d42419c`. The PumpSwap IDL SHA-256 is `2091433899b07d003d98118ae6cd3c628960fd393b40710b6e15bce6d0e7f2d1`. For a native, non-Mayhem Pump create, derive the canonical pool authority PDA from Pump seeds `['pool-authority', mint]`, then the PumpSwap pool PDA from `['pool', little-endian u16 zero, pool_authority, mint, WSOL mint]`. Check this derivation against the already observed MC-012 migration pool before cohort capture. Do not infer pool presence from a later third-party listing.

Capture one 600-second Solana Labs Pump `confirmed` log panel, maximum 512 MiB raw, with the unchanged direct Pump curve companion at receipt +7/+67 seconds and a concurrent read-only route companion. For **every** native non-Mayhem emitted create, the route companion schedules at receipt +67 seconds one `getMultipleAccounts` read of its emitted Pump bonding curve, derived canonical PumpSwap pool and PumpSwap global config in the same confirmed bank response. Dispatch by +69 seconds and require response by +72 seconds for a timely first snapshot. Preserve request/response clocks, bank context slot, raw bytes/hash, nulls and RPC errors. When the pool is present, promptly read bonding curve, pool, pool base vault, pool quote vault and global config together in a second confirmed bank response; require this second response by +75 seconds for a bounded reserve snapshot. Save all responses under a 32-MiB bound, including failed or null results, and retain every creation in companion selection. A pool that appears only in the later second response is observed then, not backdated.

Independently audit all structurally valid interior Pump signatures and logs as in MC-010: zero missing/extra valid signatures, successful-log truncation, decoder failures, native state-continuity failures or material integer quote failures. Require both companions to parse the full raw segment and attempt every scheduled read. Use later signed strict create identity only for retrospective universe validation. The route result must verify derivation, PumpSwap account owner and pinned pool discriminator/layout, pool base/quote mint and vault addresses, token-account owners/mints, AMM config owner/layout and same-response bank context. Any stale bank slot relative to a visible same-mint Pump migration or trade remains unknown. Preserve all non-native, Mayhem, late, unresolved or unscored names as explicit excluded/unknown rows.

## Comparison and decision

Use the unchanged 70/30 temporal split and direct Pump account entry/exit quote states from MC-013/015. Report, separately for direct Pump curve `QUOTED`, `EXIT_UNAVAILABLE`, and entry/fee-state unknown cases, the number with timely canonical pool absent, present with fully decoded vaults, present but incomplete/stale, or missing route read. Report canonical migration/completion events by each saved route response clock and all response lags. A confirmed null pool at one bank slot means **canonical pool absent at that observed snapshot only**. It neither proves no other venue nor establishes zero liquidation value. A decoded pool/vault state is route depth evidence, not a size-aware cash quote until PumpSwap fee and integer swap semantics are separately validated against observed transactions. No inventory recovery, Rocket order inclusion, priority-fee choice, fill or `ENTER` is inferred.

This is an acquisition/route-truth experiment, not an economic promotion gate. If exact stream coverage or complete companion capture fails, classify the relevant route outcomes unknown and preserve the failed panel. If the route state is available, continue with a separately frozen size-aware quote and inclusion calibration; if absent for all curve-unavailable cases, other-venue and achieved liquidation remain open rather than declared impossible.
