# MC-007 frozen design — simultaneous public websocket acquisition benchmark

Parent MC-006. This is an infrastructure experiment, not a strategy, feature or outcome search. MC-005/MC-006 matched long-window signatures on the current `api.mainnet-beta.solana.com` websocket but had repeated 10–45-second receipt-age bursts. An eight-second test of `solana-rpc.publicnode.com` websocket missed 466/871 independent interior signatures and is rejected. An eight-second test of Solana's documented `api.mainnet.solana.com` alias matched 1,122/1,122 and had a 1.447-second block-time-to-receipt p90, but is too short to trust.

Before starting the new sessions, freeze a **simultaneous** 120-second read-only benchmark of `wss://api.mainnet-beta.solana.com` and `wss://api.mainnet.solana.com`, using the same v2 bounded collector and at most 128 MiB per feed. Start them within a few seconds. Preserve each raw spool, manifest, original frame receipt time and checksum. Audit each against `getSignaturesForAddress` from `solana-rpc.publicnode.com`, not its own HTTP host. Require exact independent signature coverage in each feed's fully observed interior slots; exclude the first/last observed slot.

Measure on the **intersection of both feeds' verified interior slots**: signature coverage and paired receipt time difference (`mainnet` receipt minus `mainnet-beta` receipt) for common signatures. Report median, p90, p99, max and fraction slower by over five seconds. Separately report each feed's whole-second block-time-to-receipt distribution and CreateEvent timestamp-to-receipt distribution. These clocks are not exact physical network latency, but paired same-signature receipt times permit a direct relative comparison. Preserve missing signatures, slot disagreements and all errors. Do not select only favorable minutes or signatures after seeing timing.

A feed is eligible for a longer prospective validation only if it has exact independent interior coverage, no collector error, and a CreateEvent receipt-age p90 at most five seconds in this two-minute benchmark. That is a necessary screen, not proof of a sustained actionable stream. If both pass, prefer the feed with lower paired receipt-time tail and test it in a longer future window. If neither passes, investigate a dedicated stream or Geyser path before another strategy holdout. No trading or order submission is involved.
