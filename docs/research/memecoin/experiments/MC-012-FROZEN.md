# MC-012 frozen design — later alternate-pool discovery diagnostic

Parent MC-010/MC-011. MC-010 modeled 54 native non-Mayhem exits as unavailable on the Pump bonding curve at the 67-second horizon; none had a same-mint completion/migration event in its covered Pump log panel. This read-only diagnostic asks whether a separate DEX pool is **discoverable later** for those names. It does not measure a quote or prove liquidity existed at the original exit clock. The official [DEX Screener token-pairs endpoint](https://docs.dexscreener.com/api/reference) returns pools by Solana mint without an API key; a single pre-design capability request returned a Pump pair for one unavailable mint.

Freeze the full 54 MC-010 `EXIT_UNAVAILABLE:insufficient exit liquidity` mint set and 54 controls chosen from the 129 `QUOTED` MC-010 names by ascending `(SHA256('mc012:' + mint), mint)`. Save mint, group, create receipt and target exit clock (`create receipt + 67 seconds`), along with source hashes, before querying the endpoint. Request `GET /tokens/v1/solana/{mint1,...,mintN}` in fixed groups of at most 30 mints. Save every request list, request/receive clock, HTTP status, body or transport error, and raw-response hash. Retry a failed batch at most twice with fixed pause; never replace an unsuccessful attempt. Do not use an unauthenticated response as an executable quote.

For every selected mint, report all returned pair addresses, DEX identifiers, base/quote mints and `pairCreatedAt`, matching the selected mint exactly. Distinguish Pump's own `pumpfun` DEX label from other venues. An other-venue pair with `pairCreatedAt <= frozen exit clock` is only a **candidate** for later chain-state verification; the third-party timestamp and later listing cannot establish the pool's reserves, order route, size-aware output or availability at the original clock. A later-created pair is impossible as a contemporaneous exit by this timestamp screen, subject to the timestamp's accuracy. Missing API pairs or failed responses are `UNKNOWN`, not proof no route existed. Report both unavailable and control groups, all missing/ambiguous responses, and bounds on possible candidates. No strategy rank, zero-recovery stress result or Rocket decision may be changed by this diagnostic.
