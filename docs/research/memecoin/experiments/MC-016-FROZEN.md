# MC-016 frozen diagnostic — signed buyer payer overlap

Parent MC-015. The economic dispersion rank failed, and distinct token-account owners still do not establish independent control. This bounded diagnostic asks whether the already archived MC-015 signed first-three buy transactions reveal **positive evidence of a common transaction fee payer** among different token owners by each creation's five-second checkpoint. It is not a new strategy test and does not reuse MC-015 returns to choose a rule.

Use only MC-015's immutable signed-buyer responses and audited actor result. Require the MC-015 actor data gate and verify its source SHA-256 against the archived primary audit. Retain every selected core buy as a denominator row. A usable row must have a unique signed token owner and a successful transaction response received by creation receipt +5 seconds. Preserve late, ambiguous and missing rows as unknown. For each creation with at least two timely usable selected buys and at least two distinct token owners, count whether two distinct owners' transactions used the same signed fee payer. Also report fee-payer equals owner, owner is a signer, and the number of distinct payers, with exact numerator and denominator. Count payers repeated across creations separately, with no claim that this links beneficial control.

The cheap falsifier for a **positive shared-payer observation** is zero same-payer/different-owner pairs in this selected sample. If present, report only that on-chain transactions shared a fee payer; this can be a relayer or sponsor and is not proof of shared funding or beneficial ownership. If absent, report that this narrow diagnostic did not observe common payers; distinct payers do not establish independent funding. No economics are tested, no MC-015 score is retuned, and no `ENTER` promotion is allowed. Reproduce the report deterministically from the archived MC-015 result.
