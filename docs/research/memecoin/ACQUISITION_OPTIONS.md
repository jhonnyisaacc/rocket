# Early-event acquisition options

Status: measured research routes, 2026-09-24. Read the [Frontier](MEMECOIN_FRONTIER.md) for the current decision. A provider's marketing latency is not a measured Rocket receive clock.

| Route | Direct evidence | Current use |
| --- | --- | --- |
| Solana Labs `logsSubscribe` | MC-005 and MC-006 each matched every independently indexed interior signature, but had 10–45-second CreateEvent age bursts. MC-007 and MC-009 each observed one 64-zero-byte signature frame absent from the independent chain index. MC-010 prospectively applied a structural quarantine and matched 154,144/154,144 valid interior signatures; all 310 creates met the coarse five-second age screen. MC-013, MC-015 and MC-017's pinged Python transport matched 208,728/208,728, 127,995/127,995 and 107,302/107,302 valid interior signatures in separate ten-minute windows; all creates met the coarse five-second age screen in each. | Primary read-only research panel, with valid-signature and log-completeness audit per cohort. Prior receipt bursts remain a reliability limit; late launches stay in the universe and are no-decision cases. |
| Publicnode Pump `getMultipleAccounts` | MC-013 and MC-015 scheduled confirmed bonding-curve reads at creation receipt +7/+67 seconds. All 550 and 532 responses, respectively, decoded and met the frozen 2-second dispatch/5-second response bound. Some account context slots were stale against visible trades and remained unquotable. Direct quotes for the tested entry ranks remained economically negative. | Contemporaneous read-only Pump curve-state evidence for bounded panels. It does not measure order inclusion, achieved fills or PumpSwap/other alternate-route liquidity. |
| Publicnode canonical PumpSwap `getMultipleAccounts` | MC-017 scheduled pool-PDA/curve/config reads for every 169 native non-Mayhem create at receipt +67 seconds. All 169 first responses were timely and same-bank; three present pools triggered successful same-bank base/quote-vault follow-ups. The other 166 responses had a null canonical pool, including every one of 52 depleted direct Pump curve exits. | Bounded canonical route-state truth. It does not cover noncanonical venues, size-aware cash recovery or Rocket inclusion. Pool virtual quote reserve and Token-2022/legacy vault semantics must be decoded. |
| Publicnode `getTransaction` for selected early buys | MC-014 fetched the first at most three successful buy signatures per native non-Mayhem launch as the raw log arrived; all 135 selected buys had a unique signed token-account owner by their creation's five-second checkpoint in a 180-second window. MC-015 repeated for 600 seconds: 390/401 selected buys had timely verified owners, ten responses were late and one owner ambiguous. | Bounded point-in-time signed owner source for this selection, with late/ambiguous cases retained. Availability for every trade, beneficial control and continuous reliability still require separate checks. |
| Publicnode `logsSubscribe` | An eight-second smoke test missed 466/871 independent interior signatures and had roughly 10.4-second median block age. | Rejected for early acquisition. |
| Publicnode full `blockSubscribe` | MC-008 matched 7,481/7,481 independent interior signatures, but CreateEvent age p90 was 10.872 seconds and 29 successful block-metadata logs were truncated. Independent official transaction reads later recovered 14 trade events. | Transaction audit/backfill candidate. Later complete logs cannot become early features. |
| PumpPortal free `subscribeNewToken` | MC-009's 180-second capture was 182 ms earlier at median on 44 paired names but missed 14/58 native Pump launches and included seven Bonk creations. | Rejected as the complete Pump candidate universe. Its [published data API](https://pumpportal.fun/data-api/bonk-fun-data-api/) describes creation notifications as free and trade data as metered; no paid trade stream was used. |
| Public dRPC / Ankr websockets | A read-only capability probe found dRPC's `logsSubscribe` unavailable on its free plan and Ankr's unauthenticated websocket returned HTTP 401. [dRPC documents a public WSS URL](https://drpc.org/docs/solana-api); [Ankr's plan table](https://www.ankr.com/web3-api/chains-list/solana/) lists WSS for paid plans. | No usable no-key alternate measured. These probes do not establish an outcome or latency comparison. |
| Authenticated dedicated WSS / Yellowstone | No dedicated stream credential was configured in this task's environment for a live benchmark. [Helius currently lists standard WSS on its free tier and enhanced transaction streaming on paid tiers](https://www.helius.dev/pricing). [Solana recommends private RPC for production](https://solana.com/docs/tools/production-readiness). | Next independently indexed benchmark if access becomes available. Choose on measured coverage, receive age, transaction identity and price; do not infer performance from product claims. |
| DEX Screener token-pairs API | Its [documented no-key endpoint](https://docs.dexscreener.com/api/reference) supports later pool discovery. MC-012 queried 108 frozen MC-010 names; no non-Pump pair was listed for 54 curve-unavailable names. MC-018 repeated a later 104-mint lookup on MC-017: no listed noncanonical pool for 52 depleted direct exits; the sole control PumpSwap listing was canonical and after its frozen exit. [Its listing policy](https://docs.dexscreener.com/token-listing) requires a pool transaction. | Discovery hint only. Later responses cannot reconstruct the 67-second liquidity, full route universe or a size-aware sell. `pumpswap` must be checked against the canonical PDA before labeling a noncanonical lead. |
| Jupiter Swap API route quote | [Official swap documentation](https://developers.jup.ag/docs/guides/how-to-build-a-custom-swap-with-metis) requires a portal API key for requests and describes an amount-specific quote. No key was configured for a prospective benchmark in this task's environment. | Candidate contemporaneous route source once keyed access exists; validate quote and receive clock against on-chain venue state and fees before using it as exit truth. |

Every candidate stream must preserve raw frames, receive clocks, checksums, errors and all excluded launches, then reconcile valid signed transaction identities with an independent chain index. A matching transaction list is insufficient when provider metadata truncates logs. A fast subset is only a conditional research cohort; report the late and missing launches in the denominator.
