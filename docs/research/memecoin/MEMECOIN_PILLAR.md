# Memecoin Pillar

Status: authoritative domain policy, 2026-09-24. Read after [the Research Constitution](../RESEARCH_CONSTITUTION.md) and before historical #27/#30 material.

## Product goal

Find opportunities early enough to be economically actionable and ultimately return a deterministic, structured Rocket decision. Separate `survival/lifecycle`, `manipulation/catastrophic risk`, `tradable expectancy`, `ranking` and `execution feasibility`. High graduation probability alone never implies entry. Keep execution disabled. Existing `rocket memecoin` primitives report `NO_EDGE_VALIDATED`; do not treat the #30 `WATCH_ENTER` label as an order.

The working lifecycle is creation → early seconds/blocks → bonding curve → completion/migration → PumpSwap. Preserve token identity as chain plus mint, source and observation clocks, protocol and fee versions, and raw provenance. Capture every candidate and rejected/missing case to measure selection bias. A retrospective chain read is available when retrieved, even if its block time is earlier. The earliest reliable point established in a bounded research session is the **receipt of a Pump `CreateEvent` log frame**, whose pinned IDL bytes carry mint and initial curve state. The independent transaction response can arrive later. This is an observed capture point, not the token creation/block time or proof that `main` has a continuously running production collector. Historical chain events cannot be silently promoted into live early features. Verify both transaction coverage and event-log completeness: a matching signature index does not prove that every trade event was emitted or retained, as MC-008's truncated logs demonstrate.

Use simple survival and return baselines before nonlinear tabular models. Participant history is a candidate feature, with sample-size shrinkage and strict wallet-buy accounting. Holder concentration requires exclusion of pool/vault accounts. Model quote-side reserves under the correct protocol version and execute with size, fees, latency, failures, slippage and exit coverage. A quoted pool state is not an achieved fill. Preserve separate entry and exit experiments.

MC-010's independently covered fast-receipt cohort repeated a lower modeled curve-exit-unavailability rate for high early net flow, while its costed entry stress returns remained negative. Treat early flow as an unpromoted risk component. Verify beneficial buyers, alternate exit liquidity and actual inclusion before any production decision uses it.

An eventual JSON decision may express `ENTER`, `WATCH`, `WAIT`, `AVOID` or `NO_TRADE` with mint, lifecycle, discovery, survival, risk, expectancy, liquidity, participant context, trigger, execution estimate, invalidation, reasons and uncertainty. The vocabulary is provisional. No production recommendation is authorized by this document.
